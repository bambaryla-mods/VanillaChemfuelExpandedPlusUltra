---
summary: The DLCs and other mods this mod supports, and what each one changes.
---
None of these are required. Each feature turns on by itself when the mod it needs is active.

## DLCs and big mods

| Mod | What changes |
|---|---|
| Biotech | Adds the [toxic waste network](toxic-waste.html), the detofixier and dye from waste. Pollution pumps, gestators and other waste makers connect to the network. |
| Combat Extended | Adds the [FSX and prometheum](combat-extended.html) refineries and networks. |

## Other mods

| Mod | What changes |
|---|---|
| Vanilla Helixien Gas Expanded | With Combat Extended, the FSX refinery can use helixien gas. Helixien pipes join the same architect dropdowns, and the gas-powered smelter takes the plasteel recipes. |
| Vanilla Races Expanded - Android | Shares the neutroamine network, so pipes and tanks from either mod connect. |
| Toxic Wastepack Generator Plus | This mod's toxic waste network replaces its pipes. On a running save, rebuild them. |
| Neutroamine Cooler | The Vanilla Expanded Framework lets it use the neutroamine network. |
| Vegetable Garden Project (Garden Fabrics) | Looms can weave unrefined fibers into synthread, hyperweave or devilstrand. |
| Vanilla Furniture Expanded - Production | The large tailoring table takes the unrefined fiber recipes, and the fueled smelter takes the plasteel recipes. |
| Advanced Pollution Pump | Its pumps also feed the toxic waste network. |

## Load order

Load this mod after Harmony, the Vanilla Expanded Framework, Vanilla Chemfuel Expanded and, if you use them, Combat Extended, Vanilla Helixien Gas Expanded and Toxic Wastepack Generator Plus. The mod's About file lists this order, so RimWorld's auto-sort gets it right.
